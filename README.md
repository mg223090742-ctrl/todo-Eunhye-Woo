# 우은혜의 할 일 목록

HTML, CSS, JavaScript로 만든 할 일 웹앱이에요. 할 일은 Supabase에 저장되어서 새로고침하거나 다른 기기에서 열어도 그대로 남아 있어요.

**사이트 주소:** https://todo-eunhye-woo.vercel.app

## 주요 기능

- 할 일 추가, 완료 체크, 삭제
- 할 일 글자를 두 번 눌러 고치기 (Enter는 저장, Esc는 취소)
- 작성자 이름과 마감일 적기 (둘 다 안 적어도 돼요)
- 마감이 가까운 순서로 정렬하고, 마감일이 없는 할 일은 아래쪽에 표시
- 마감이 지났는데 끝내지 못한 할 일은 빨갛게 표시
- 전체 · 진행중 · 완료 골라 보기와 남은 할 일 개수
- 할 일을 추가하면 "화이팅!" 문구가 잠깐 떴다가 사라짐
- 저장에 실패하면 화면에 오류 내용 표시

## 사용한 기술

| 기술 | 하는 일 |
|---|---|
| HTML · CSS · JavaScript | 화면과 동작 (프레임워크 없이 만들었어요) |
| [Supabase](https://supabase.com) | 할 일 저장 |
| [Vercel](https://vercel.com) | 사이트 배포 |

## 파일 구성

```
todo-app/
├── index.html   화면의 뼈대 (입력칸, 버튼, 목록 자리)
├── style.css    화면 꾸미기
├── app.js       할 일을 불러오고, 추가하고, 고치고, 지우는 동작
└── config.js    Supabase 주소와 publishable key
vercel.json      Vercel에서 todo-app 폴더를 보여 주는 설정
```

## 데이터 구조

할 일은 Supabase의 `todos` 표에 한 줄씩 저장돼요.

| 칸 | 내용 | 비워 둘 수 있나요 |
|---|---|---|
| `id` | 할 일 번호 (자동으로 붙어요) | 아니요 |
| `text` | 할 일 내용 | 아니요 |
| `done` | 완료했는지 여부 | 아니요 (처음엔 완료 안 함) |
| `author` | 작성자 이름 | 예 |
| `due_date` | 마감일 | 예 |
| `created_at` | 추가한 시각 (자동으로 기록돼요) | 아니요 |

## 내 컴퓨터에서 실행하기

1. 이 저장소를 내려받아요.
2. `todo-app/index.html`을 브라우저로 열어요.

따로 설치할 것은 없어요. 다만 할 일을 불러오고 저장하려면 인터넷에 연결되어 있어야 해요.

## 보안 안내

- 이 앱은 **로그인 없이 누구나** 할 일을 읽고, 추가하고, 고치고, 지울 수 있게 만들었어요. 사이트 주소를 아는 사람은 다른 사람이 적은 할 일과 작성자 이름도 볼 수 있으니, 비밀이나 개인 정보는 적지 마세요.
- `config.js`에 있는 publishable key는 브라우저에 공개되라고 만든 열쇠라서 저장소에 올라가 있어도 괜찮아요. 무엇을 할 수 있는지는 Supabase의 권한 규칙(RLS)이 정해요.
- 비밀 열쇠(secret key)는 이 저장소에 넣지 않아요.
